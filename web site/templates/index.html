About The Project

A Smart Nutrition Analysis System for Real-Time Food Health Monitoring and Diet Management

Modern lifestyles often lead to irregular dietary habits, hidden caloric excess, and micronutrient deficiencies. NutriSmart was developed as a comprehensive college minor project prototype to bridge the gap between nutritional science, computer vision, and user-friendly web interfaces.

The platform integrates Python Flask, SQLite with SQLAlchemy ORM, Chart.js interactive visualization, and a modular image processing pipeline designed to support deep learning classification models such as MobileNetV2 and ResNet.

Project Architecture
  • Backend Framework Python Flask 3.0
  • Relational Database & ORM SQLite + SQLAlchemy
  • Frontend Interface HTML5, CSS3, Bootstrap 5, JS
  • Visual Analytics Chart.js 4.4
  • Vision & Image Processing Pillow / Modular Keras Hook
  • Security & Sessions Werkzeug Security
Project Limitations
  • Prototype Food Recognition: Accuracy is subject to pre-defined classes and image clarity. Currently utilizes a modular heuristic prototype designed for educational demonstration.
  • Approximate Nutritional Values: Database figures represent standard USDA/ICMR averages; actual prepared dishes vary by ingredients and cooking oils.
  • Portion Estimation: Estimation from 2D images is approximate; users are encouraged to verify portion weights.
  • Informational Guidance: The system is strictly non-medical and does not replace registered dietitians or physicians.
Future Enhancements
  • Deep Learning Vision: Train custom convolutional neural networks (CNNs) on Food-101 and Indian Food datasets via TensorFlow/Keras.
  • Automated 3D Volume Estimation: Depth sensor & AR camera integration for automated portion size measurement.
  • Wearable & CGM Integration: Sync with Apple Health, Google Fit, and Continuous Glucose Monitors (CGM).
  • Conversational AI Assistant: Voice-activated food logging using speech-to-text models.
